# Deliberately absent: torch, FlagEmbedding, qdrant-client, xgboost.
#
# Retrieval here is lexical with LLM reranking rather than BGE-M3 dense search.
# BGE-M3 is XLM-RoBERTa-large — roughly 568M parameters, about 2.2 GB at fp32
# and 1.1 GB at fp16, before the PyTorch runtime — against Render's 512 MB free
# tier. At a corpus of a few hundred real passages the retrieval quality gap is
# far smaller than the gap between real documents and invented ones, so the
# money goes on the corpus.
#
# XGBoost is absent because the model it served learned a rulebook it had been
# handed: the training label was computed from each row's own wind and wave, and
# those same columns were then fed back in as features. See docs/orca-backlog.md.
